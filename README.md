# Violetta — hero-блок

Первый экран лендинга: ночное сиреневое небо с мерцающими звёздами и
дрейфующими облаками, editorial-заголовок со сменяемым словом и закатные
слои, которые поднимаются по скроллу и открывают второй экран.

Перенос дизайна `Hero v2` из Claude Design в статический HTML/CSS/JS.

## Запуск

Сборка не нужна — откройте `index.html` в браузере.

Чтобы шрифты и `100svh` вели себя как на проде, лучше поднять локальный
сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Деплой на GitHub Pages: Settings → Pages → Source: `main` / `root`.

## Структура

```
index.html                разметка первого экрана
assets/css/hero.css       вся вёрстка и состояния (hover / active / focus)
assets/js/hero.js         движение: звёзды, дрейф облаков, смена слова, скролл
assets/img/*.webp         иллюстрации облаков
```

## Как устроен скролл

`.hero` — липкий блок высотой `100svh`, под ним `.hero-spacer` высотой
`130vh`. Скролл по этой полосе даёт прогресс `p` от 0 до 1:

```
p = window.scrollY / (высота вьюпорта × 0.85)
```

От `p` зависит всё: небо уезжает вверх на `96svh`, закатные слои поднимаются
и увеличиваются с разной скоростью (отсюда ощущение наложения), контент
первого экрана уходит вверх и растворяется, ночные облака и звёзды гаснут, а
тизер «Есть 10 минут?.. Давайте творить магию» проявляется во второй
половине пути.

Небо — это одна закруглённая панель на кремовом фоне (`border-radius` на
самом небе, а не отдельный слой под ним), поэтому у края арки не бывает
тёмного просвета.

## Движение

Всё движение считается в JS-кадрах (25 к/с), а не CSS-анимациями. Это
сделано намеренно: в исходной среде дизайна системная настройка «уменьшить
движение» глушила CSS-анимации и облака стояли на месте. По той же причине
здесь **нет** `prefers-reduced-motion` — вместо него один явный тумблер в
начале `assets/js/hero.js`:

```js
var MOTION = true;   // false — сцена замирает, скролл-эффект продолжает работать
```

Слово в заголовке меняется каждые 3,4 с по циклу
`запомнят → полюбят → будут петь → не забудут`: уход вверх с размытием и
лёгким сжатием (560 мс, ease-in), затем возврат снизу (620 мс, ease-out).
Строка зафиксирована по высоте (`height: 1.14em`), поэтому заголовок не
дёргается.

Звёзды (46 шт.) расставлены хеш-рандомом — раскладка одинакова при каждой
загрузке, но позиции, размеры (1,1–3 px), фазы и скорости мерцания у всех
разные, и они плотнее к верху неба.

## Что можно поменять в первую очередь

| Что | Где |
| --- | --- |
| Название бренда | `.nav__brand` в `index.html` |
| Слова в заголовке | `WORDS` в `assets/js/hero.js` |
| Скорость смены слова | `CYCLE` / `OUT` / `IN` там же |
| Количество звёзд | `STAR_COUNT` там же |
| Градиент неба | `.hero__sky` в `assets/css/hero.css` |
| Длина скролл-эффекта | `.hero-spacer` там же |

`position`, как и задумано в дизайне.

## Шрифты

Playfair Display (заголовки), Marck Script (логотип и сменяемое слово),
Manrope (интерфейс) — подключены с Google Fonts. Если нужен офлайн или
самохостинг, положите файлы в `assets/fonts/` и замените `<link>` на
`@font-face`.

## Отличия от прототипа

- **Скролл на документе, а не внутри блока.** В прототипе прокрутка жила
  внутри самого hero — это был обходной путь, `position: sticky` не работал
  в предпросмотре дизайн-инструмента. На реальной странице этого ограничения
  нет, поэтому эффект переведён на скролл документа. Визуально и по
  таймингам поведение то же.
- **Узкие экраны (≤ 520 px).** В прототипе на 390 px пилюля navbar не
  вмещала все четыре элемента, а коралловая пилюля — строку в одну линию,
  и оба блока обрезались. Добавлен один медиазапрос: «Как это работает»
  скрывается, коралловая пилюля переносится в две строки. Десктопная
  композиция не тронута.
