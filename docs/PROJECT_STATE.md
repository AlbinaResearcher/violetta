# Состояние проекта — 12 сентября 2026

Исходная точка: `alyalbina/violetta`, `main`, `e6140061111e05b5cc938f00ed26f77d216466ff`.
Рабочая ветка: `feature/vivobit-responsive`.

## Восстановление

В upstream был один коммит hero, только ветка main. Локальная рабочая копия создана заново; незакоммиченных пользовательских изменений не было. Инструкций AGENTS.md в проекте и архивах не найдено.

После проверки истории и файлов применены четыре коммита из changes.patch. Содержимое совпало с vivobit-landing-handoff.zip после нормализации CRLF/LF; иллюстрации совпали побайтно. Патч не дублирует изменения upstream. Исходный экспорт Claude Design просмотрен отдельно; сохранены разделы, палитра, шрифты и авторские иллюстрации.

## Текущий результат

- Полный статический лендинг «Вивобит», документы privacy.html / offer.html.
- Адаптивные карточки, меню, форма, короткий мобильный hero и режим низкого окна.
- Ошибки у полей, отдельные черновики контактов, возврат без потери ввода, реальное копирование в буфер с ручным fallback.
- WebP-иллюстрации и lazy-loaded миниатюры; основной набор уменьшен примерно с 14,3 МБ до 0,44 МБ.
- 19 автоматических тестов пройдены; браузерная проверка описана в RELEASE_QA.md.

## Ограничения продукта

Аудиофайлов и аудио-URL нет ни в архиве, ни в коде. Плеер не имитирует звук. Для подключения нужны пять записей и значения audioSrc в assets/js/site-data.js.

Backend/CRM отсутствует. Посетитель готовит и копирует сообщение, затем самостоятельно отправляет его в https://t.me/vivo_support. Успешная доставка сайтом не заявляется; тестовых сообщений менеджеру не отправляли. Клиентских секретов нет.

Тексты юридических документов совпадают с исходным экспортом (проверено по нормализованному тексту main). Правовая оценка не выполнялась, условия не переписывались.
