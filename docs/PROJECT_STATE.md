# Violetta — состояние проекта, 12 сентября 2026

## Current state

Исходная точка: `main`, `e6140061111e05b5cc938f00ed26f77d216466ff`.
На момент проверки найдена одна ветка (`main`), один коммит, открытых PR нет.

Продукт по коду: лендинг персональных песен. Первый сценарий — познакомиться
с предложением и начать создание песни. Аудитория и полный заказной сценарий
отдельно не описаны. Не следует переносить сюда сущности других проектов.

Стек: одна HTML-страница, один CSS-файл, один JS-модуль (IIFE), пять WebP
иллюстраций и SVG favicon. Нет package.json, React/Next.js, TypeScript,
маршрутизатора, API, mock data, хранилища состояния продукта, UI-kit,
Storybook, CI или дополнительных дизайн-документов. Это небольшой статический
проект; отсутствие фреймворка само по себе не является проблемой.

Реализованы hero, навигационная пилюля, H1 со сменой слова, CTA, social proof,
46 детерминированных звёзд, три дрейфующих облака, два закатных слоя и тизер.
Есть fluid-размеры через clamp/min/vw/vh/svh и breakpoint ширины 520 px.
Поток создания песни, вход, объяснение процесса и следующие разделы отсутствуют.
Четыре функциональные ссылки остаются `href="#"`.

- Значения spacing/radius/shadows заданы в CSS, отдельного слоя токенов нет.

## Первый этап продолжения

Ветка `gpt-development/hero-accessibility`:

- Пауза фоновой анимации и слова; поддержка системного reduced motion.
- Остановка кадров и таймеров в скрытой вкладке и после исчезновения контента.
- Исключение невидимого контента из фокуса/кликов и дерева доступности.
- Семантические main/nav, постоянное доступное имя H1, фокус навигации.
- Статичная композиция при высоте ≤650 px и без JS; перенос тизера на mobile.
- Защита высоты CTA от flex-сжатия.
- Семь тестов жизненного цикла анимации без внешних зависимостей.

Иллюстрации, текст предложения, шрифты, основные цвета и исходные тайминги
не менялись. Новый продуктовый сценарий не выдумывался.

## Проверки и ограничения

Пройдены `node --check assets/js/hero.js`, 7 тестов `node --test` и
`git diff --check`. TypeScript/import/build проверки неприменимы к текущему стеку.
Тесты используют контролируемую DOM-среду; браузерную отрисовку не проверяют.

Облачный браузер отказался открывать локальный сервер:
`net::ERR_BLOCKED_BY_CLIENT`. Скриншоты, реальные responsive-замеры,
загрузка шрифтов, визуальная регрессия и контраст не подтверждены.

План ручной проверки: 1440×900 (desktop), 1366×768 (laptop), 768×1024
(tablet), 390×844 и 320×568 (mobile), 844×390 (landscape); обычный и
reduced-motion режимы, клавиатура, скролл туда/обратно, отключённый JS.

GitHub metadata сообщает `pull: true`, `push: false` для текущего подключения.
Ветка и коммиты подготовлены локально. Удалённая ветка, PR и деплой не созданы.
